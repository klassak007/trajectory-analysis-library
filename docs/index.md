# TAL Documentation

TAL is an xarray-native trajectory analysis library. It keeps labeled
scientific data in `xarray` objects and adds enough semantic metadata for
trajectory operations to stay explicit about sequence axes, batch structure,
payload dimensions, parameter coordinates, validity, components, and frames.
